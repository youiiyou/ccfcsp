# CCF CSP 201403-3 命令行选项 — 解题笔记

> 纯字符串模拟题，不涉及算法，关键是准确理解"停止"条件与几个输出细节。

## 1. 题目要点

- **格式串**（第一行，如 `albw:x`）声明哪些选项合法、是否带参：
  - 字母后**无冒号** → 无参数选项（`a`、`l`、`b`、`x`）；
  - 字母后**紧跟冒号** → 带参数选项（`w:`）。
- **解析规则**：从命令名之后**从左到右**扫，遇到第一个"既不是合法选项、也不是合法选项参数"的字符串就**立刻停止**，剩余部分全部忽略。
- **输出规则**：
  - 选项按**字母升序**输出；
  - 同一选项出现多次只算一次；
  - 带参选项多次出现时**只输出最后一次的参数**。

## 2. 样例对照（理解题意用）

格式串 `albw:x`：`a / l / b / x` 无参，`w` 带参。

| 命令行 | 解析过程 | 输出 |
|---|---|---|
| `ls -a -l -a documents -b` | `-a`✓ `-l`✓ `-a`✓(重复) → `documents` 不是选项 → **停**，`-b` 忽略 | `Case 1: -a -l` |
| `ls` | 无选项 | `Case 2:` |
| `ls -w 10 -x -w 15` | `-w` 吃参数 `10`，`-x`✓，`-w` 再吃 `15`（**覆盖** 10） | `Case 3: -w 15 -x` |
| `ls -a -b -c -d -e -l` | `-a`✓ `-b`✓ → `-c` 不在格式串 → **停** | `Case 4: -a -b` |

注意第 4 行：`-c` 形态虽合法，但格式串里没有 `c`，**必须停**，`-d -e -l` 全被忽略。

## 3. 算法步骤（4 步）

1. **建表**
   - 读格式串，对每个字母记录：
     - `valid[c]`：格式串里有没有这个字母（是否可选）；
     - `hasArg[c]`：它后面是否紧跟冒号（是否带参）。
   - 遇到冒号直接跳过。

2. **切词**
   - 每条命令行整行 `getline`，按空格切成字符串数组；
   - `tokens[0]` 是命令名，忽略，从下标 1 开始扫。

3. **从左到右扫描**，命中以下任一条就 `break`（剩余忽略）：
   - 字符串不是 `"-" + 单个小写字母` 形态（如 `documents`、`-a1`、`--`、`-`）；
   - 形态合法但**字母不在格式串里**（样例中的 `-c`）；
   - 是带参选项但**后面已没有字符串可作参数**。

   处理：
   - 无参选项 → 标记用过，下标 +1；
   - 带参选项 → 直接吃下一个字符串当参数**覆盖保存**（天然实现"取最后一次"），下标 +2。

4. **输出**
   - `Case i:`，从 `a` 到 `z` **升序**遍历输出用到的选项；
   - 带参的选项再输出一个空格 + 参数；
   - 无选项时只输出 `Case i:`（行尾不加多余空格）。

## 4. 易踩的坑

1. **合法性判断必须恰好长度 2**：`-a1` 不是合法选项，容易漏判。
2. **停止是一次性的**：遇到非法串立刻停，后面的 `-b -c` 再合法也不处理（样例 1、4 都在考这个）。
3. **参数覆盖**：带参选项多次出现，只保留最后一次的参数（样例 3：`-w 15` 覆盖 `-w 10`）。
4. **排序是字母序**，不是出现顺序；重复选项只输出一次。
5. **格式**：`Case i:` 后恰好一个空格，选项间单空格；空选项行不要拖尾空格。
6. 命令行里的字符串保证只含小写字母/数字/减号，所以带参选项后的下一串**一定**是合法参数，直接吃掉，无需再校验。

## 5. 完整代码（C++17）

```cpp
// CCF CSP 201403-3 命令行选项
#include <bits/stdc++.h>
using namespace std;

bool valid[256];     // 该字母是否是格式串声明的合法选项
bool hasArg[256];    // 该选项是否带参数
bool used[256];      // 本命令行中该选项是否被用到
string lastArg[256]; // 带参选项最后一次出现的参数

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string fmt;
    cin >> fmt;
    for (int i = 0; i < (int)fmt.size(); i++) {
        if (fmt[i] == ':') continue;
        valid[(unsigned char)fmt[i]] = true;
        if (i + 1 < (int)fmt.size() && fmt[i + 1] == ':')
            hasArg[(unsigned char)fmt[i]] = true;
    }

    int n;
    cin >> n;
    string line;
    getline(cin, line); // 吃掉第一行末尾换行

    for (int kase = 1; kase <= n; kase++) {
        getline(cin, line);
        stringstream ss(line);
        vector<string> t;
        string w;
        while (ss >> w) t.push_back(w); // 命令名是 t[0]

        memset(used, 0, sizeof used);
        for (auto &s : lastArg) s.clear();

        for (int i = 1; i < (int)t.size(); ) {
            const string &s = t[i];
            // 合法选项必须恰好是 "-" + 单个小写字母, 且字母在格式串中
            if ((int)s.size() != 2 || s[0] != '-' ||
                s[1] < 'a' || s[1] > 'z' ||
                !valid[(unsigned char)s[1]])
                break;

            char c = s[1];
            if (hasArg[(unsigned char)c]) {
                if (i + 1 >= (int)t.size()) break; // 需要参数但后面没有
                lastArg[(unsigned char)c] = t[i + 1]; // 覆盖 = 只留最后一次
                used[(unsigned char)c] = true;
                i += 2;
            } else {
                used[(unsigned char)c] = true;
                i += 1;
            }
        }

        cout << "Case " << kase << ":";
        for (char c = 'a'; c <= 'z'; c++) { // 按字母升序输出
            if (used[(unsigned char)c]) {
                cout << " -" << c;
                if (hasArg[(unsigned char)c]) cout << ' ' << lastArg[(unsigned char)c];
            }
        }
        cout << '\n';
    }
    return 0;
}
```

## 6. 验证结果

样例输入与输出完全一致（GCC 13.2，`-std=c++17`）：

```
输入:
albw:x
4
ls -a -l -a documents -b
ls
ls -w 10 -x -w 15
ls -a -b -c -d -e -l

输出:
Case 1: -a -l
Case 2:
Case 3: -w 15 -x
Case 4: -a -b
```

边界用例也通过：

| 输入行 | 结果 | 说明 |
|---|---|---|
| `ls -b`（格式 `ab:m:`，b 带参） | `Case 1:` | 带参但缺参数 → 停止，不输出 |
| `ls -a1 -b` | `Case 2:` | `-a1` 非合法形态 → 停止 |
| `ls -m -a -m 42` | `Case 3: -m 42` | `-a` 被 `-m` 当参数吃掉；`-m 42` 覆盖前值 |
